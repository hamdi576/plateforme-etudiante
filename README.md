# Plateforme Étudiante – Projet Web

## Structure du dossier
- `index.html` : Structure principale de l'application web.
- `style.css` : Feuille de style (mise en page, thème clair et sombre automatique).
- `app.js` : Logique applicative (connexion Gmail, extraction d'emploi du temps depuis une image via Gemini Vision, gestion des matières, validation des fichiers et assistant IA).

## Instructions d'utilisation
1. Extrayez tous les fichiers de cette archive dans un même dossier.
2. Ouvrez `index.html` dans un navigateur web moderne (Chrome, Edge, Firefox).
3. Connectez-vous avec une adresse `@gmail.com` (mode démo) ou configurez `GOOGLE_CLIENT_ID` dans `app.js`.
4. Lors de la première connexion, cliquez sur **Importer une image** pour générer automatiquement l'emploi du temps, ou saisissez vos séances manuellement.
5. (Optionnel) Cliquez sur le bouton **Clé API Gemini** pour activer l'analyse réelle d'images et l'assistant IA génératif.
